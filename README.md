# StartupHub

Exploración de servicios para startups venezolanas. App móvil construida con React Native (Expo) + TypeScript.

## Propósito

Este proyecto tiene como objetivo proporcionar una plataforma centralizada para descubrir y gestionar servicios orientados a emprendedores y startups en Venezuela. Permite filtrar por categorías, ver detalles de cada servicio y realizar solicitudes directas.

## Requisitos

- Node.js >= 20.x
- npm

## Instalación y ejecución

```bash
npm install
npx expo start
```

Luego escanea el código QR con la aplicación **Expo Go**, o presiona `w` para la versión web, `a` para Android, o `i` para iOS.

## Estructura del proyecto

```
src/
  components/     # Componentes reutilizables (UI, Layout)
  screens/        # Pantallas principales de la aplicación
  hooks/          # Lógica de negocio y manejo de estado
  types/          # Definiciones de tipos TypeScript
  data/           # Datos estáticos y mocks para desarrollo
  assets/         # Imágenes y recursos estáticos
```
